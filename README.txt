VN30 PUBLIC PANEL — CLEANING OUTPUTS

Stock count: 30
Balanced sample: 2018-06-04 to 2023-06-30
Balanced trading dates: 1260

Files:
- vn30_cleaned_long.csv: all deduplicated stock observations in long format.
- vn30_balanced_close_2018_2023.csv: balanced close-price panel.
- vn30_balanced_log_returns_2018_2023.csv: balanced daily log-return panel.
- vn30_balanced_volume_2018_2023.csv: balanced volume panel.
- vn30_balanced_value_2018_2023.csv: balanced traded-value panel.

Important limitations:
- Prices are raw, not verified corporate-action-adjusted prices.
- The dataset is treated as a fixed VN30-associated panel, not reconstructed historical membership.
- Zero traded value should be treated as missing in illiquidity calculations.
